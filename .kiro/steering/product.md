# Product Overview

This is a code console extension for 1C:Enterprise 8.3 (1С:Предприятие) that embeds the Monaco Editor into managed forms. It provides a modern code editing experience with syntax highlighting, autocomplete, and query construction capabilities for BSL (Built-in Script Language) and 1C query language.

## Key Features

- Monaco Editor integration for BSL code editing
- Syntax highlighting for 1C:Enterprise BSL and query language
- Query constructor integration
- Format string constructor
- Code bookmarks and navigation
- Multiple theme support (light/dark, EDT-style)
- Error markers and diagnostics display
- Multi-page code editing with context preservation
- Read-only mode support

## Target Platform

1C:Enterprise 8.3 (minimum version 8.3.14.1565, tested on 8.3.23.1865)
