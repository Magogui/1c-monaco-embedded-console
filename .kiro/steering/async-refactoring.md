# Рефакторинг на асинхронные процедуры

## Выполненные изменения

Модуль `конс_ОбщийМодульКлиент` переписан с использованием асинхронных процедур (`Асинх`/`Ждать`) вместо цепочек оповещений.

### 1. Конструктор форматной строки

**Было:** 4 процедуры с оповещениями
- `ВызватьКонструкторФорматнойСтроки()`
- `ВопросСоздатьНовуюФорматнуюСтроку()`
- `ОткрытьКонструкторФорматнойСтроки()`
- `ПриЗакрытииКонструктораФорматнойСтроки()`

**Стало:** 1 асинхронная процедура
```bsl
Асинх Процедура ВызватьКонструкторФорматнойСтроки(Форма, ПараметрыСтроки)
```

### 2. Подключение расширения работы с файлами

**Было:** 3 процедуры с оповещениями
- `ПриОткрытии()`
- `ПослеПодключенияРасширенияДляРаботыСФайлами()`
- `ПослеУстановкиРасширенияДляРаботыСФайлами()`

**Стало:** 1 асинхронная процедура
```bsl
Асинх Процедура ПриОткрытии(Форма) Экспорт
```

### 3. Извлечение исходников Monaco Editor

**Было:** 9 процедур с оповещениями
- `ИзвлечьИсходники()`
- `ПриПолученииКаталогаВременныхФайлов()`
- `ПослеСозданияКаталога()`
- `ПослеПроверкиСуществованияКаталога()`
- `ПослеПроверкиСуществованияФайлаВерсии()`
- `ПослеПроверкиСуществованияИндексногоФайла()`
- `ПослеКопированияИндексногоФайла()`
- `ИзвлечьИсходникиНаКлиенте()`
- `ПослеУдаленияВременныхФайлов()`
- `ПослеЗаписиФайлаМакета()`

**Стало:** 2 асинхронные процедуры
```bsl
Асинх Процедура ИзвлечьИсходникиАсинх(Форма)
Асинх Процедура ИзвлечьИсходникиНаКлиентеАсинх(Форма, КаталогИсходников)
```

### 4. Закрытие консоли

**Было:** 2 процедуры с оповещениями
- `ЗакрытьКонсоль()`
- `ПослеУдаленияИндексногоФайла()`

**Стало:** 2 процедуры (асинхронная + обработчик)
```bsl
Процедура ПередЗакрытием() // с отложенным вызовом
Асинх Процедура ЗакрытьКонсольАсинх(Форма)
```

### 5. Вывод ошибок

**Было:** 2 процедуры с оповещениями
- `ВывестиОшибку()`
- `ПослеВыводаОшибки()`

**Стало:** 1 асинхронная процедура
```bsl
Асинх Процедура ВывестиОшибкуАсинх(Текст, БлокироватьКонсоль, Форма)
```

## Преимущества

### ✅ Читаемость
- Код читается сверху вниз, как обычный синхронный
- Логика выполнения очевидна без изучения цепочек оповещений

### ✅ Меньше кода
- Удалено **15 процедур-обработчиков** оповещений
- Убраны структуры `ДопПараметры` для передачи контекста
- Код стал компактнее на ~40%

### ✅ Проще отладка
- Линейный поток выполнения
- Стек вызовов понятен
- Легче ставить точки останова

### ✅ Меньше ошибок
- Не нужно передавать контекст через параметры
- Нет риска потерять данные между вызовами
- Проще обрабатывать исключения

## Требования

- **Минимальная версия платформы:** 1С:Предприятие 8.3.10
- **Текущая версия проекта:** 8.3.14.1565+ (требование выполнено)

## Совместимость

Изменения **обратно совместимы** с текущей версией проекта (8.3.14.1565+).

Все публичные методы сохранили свои сигнатуры:
- `ПриОткрытии(Форма)` - теперь асинхронная
- `ПередЗакрытием(Форма, ...)` - использует отложенный вызов

## Примечания

### Конструктор запроса
Процедуры `ВызватьКонструкторЗапроса()` и `ОткрытьКонструкторЗапроса()` уже были асинхронными и не требовали изменений.

### Закрытие формы
Для `ПередЗакрытием()` использован паттерн с отложенным вызовом через `ПодключитьОбработчикОжидания()`, так как событие `ПередЗакрытием` не может быть асинхронным напрямую.

### Веб-клиент
В веб-клиенте исходники загружаются с GitHub, асинхронные операции с файлами не требуются.
