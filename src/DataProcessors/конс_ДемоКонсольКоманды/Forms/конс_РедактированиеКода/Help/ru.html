Демо консоль - команды

Эта обработка демонстрирует все доступные методы для работы с консолью BSL.

🎨 Управление отображением

Показать номера строк
Показывает номера строк в редакторе
Скрыть номера строк
Скрывает номера строк в редакторе

📝 Работа с текстом

Получить текст
Получает весь текст из редактора и показывает его длину
Установить текст
Устанавливает новый текст в редакторе
Очистить текст
Очищает весь текст в редакторе
Вставить строку
Вставляет комментарий в начало кода
Добавить строку
Добавляет комментарий в конец кода

✂️ Работа с выделением

Получить выделенный текст
Получает и показывает выделенный текст
Заменить выделенный текст
Заменяет выделенный текст на верхний регистр
Установить выделение
Выделяет строки со 2 по 5

📍 Координаты и позиция

Получить координаты выделения
Показывает координаты начала и конца выделения
Получить номера строк выделения
Показывает номера начальной и конечной строк выделения
Показать координаты выделения
Открывает панель с координатами выделения
Получить текущую строку
Показывает номер текущей строки курсора
Получить текущую колонку
Показывает номер текущей колонки курсора

🔍 Навигация и поиск

Найти текст
Ищет слово "Процедура" в коде
Открыть виджет поиска
Открывает панель поиска (Ctrl+F)
Перейти к строке
Открывает диалог перехода к строке (Ctrl+G)
Показать строку в центре
Показывает строку 5 в центре экрана
Перейти к парной скобке
Переходит к парной скобке

📌 Закладки

Добавить закладку
Добавляет закладку на текущую строку
Удалить закладку
Удаляет закладку с текущей строки
Получить закладки
Показывает список всех закладок

🎨 Темы оформления

Установить светлую тему
Переключает на светлую тему (bsl-white)
Установить темную тему
Переключает на темную тему (bsl-dark)
Включить режим только для чтения
Включает режим только для чтения
Выключить режим только для чтения
Выключает режим только для чтения

⚠️ Маркеры и ошибки

Установить маркеры (пример)
Устанавливает примеры маркеров: ошибку, предупреждение и информацию

✨ Дополнительные методы

Отформатировать текст
Форматирует код (Alt+Shift+F)
Показать справку
Показывает справку программно
Скрыть справку
Скрывает справку программно
Сбросить позицию кнопки помощи
Сбрасывает позицию кнопки помощи к значению по умолчанию

📖 Дополнительная информация
